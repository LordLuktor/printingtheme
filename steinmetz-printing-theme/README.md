# Steinmetz Printing WordPress Theme

A modern, responsive, block-compatible WordPress theme designed specifically for Steinmetz Printing.

## Features

- **Full Site Editing (FSE)** - Built with WordPress block theme architecture
- **Mobile-First Responsive Design** - Extensively optimized for all screen sizes (mobile, tablet, desktop)
- **Modern Design** - Clean, professional aesthetic matching your brand
- **Block Compatible** - Works seamlessly with the WordPress block editor
- **Custom Colors** - Brand colors integrated throughout the theme
- **Separate Home & Blog** - Automatically configured static home page with separate blog page
- **Accessible** - WCAG compliant with keyboard navigation support
- **WooCommerce Ready** - Full support for online store functionality
- **SEO Optimized** - Proper HTML5 markup and schema support

## Mobile & Responsive Enhancements (v2.0)

### Typography
- **Fluid Typography** - Uses CSS clamp() for smooth font scaling across all devices
- **Mobile-Optimized Sizes** - Headings and body text automatically adjust for readability on small screens
- **Viewport-Based Scaling** - Font sizes respond intelligently to screen width

### Navigation
- **Touch-Friendly Menu** - All navigation items meet 44x44px minimum touch target size
- **Enhanced Mobile Menu** - Improved mobile navigation with better spacing and visibility
- **Full-Width Mobile Items** - Menu items stack vertically and span full width on mobile for easy tapping

### Touch Targets
- **44x44px Minimum** - All interactive elements (buttons, links, form inputs) meet accessibility guidelines
- **Full-Width Buttons** - Buttons expand to full width on mobile for easier interaction
- **Optimized Form Inputs** - Form fields are touch-friendly with 16px font size to prevent zoom on iOS

### Responsive Breakpoints
- **Small phones**: < 600px
- **Tablets**: 600px - 781px
- **Tablets landscape**: 782px - 1024px
- **Desktop**: > 1024px
- **Large screens**: > 1400px
- **Landscape orientation**: Special optimizations for phones in landscape mode

### Images & Media
- **Responsive Images** - All images scale properly and maintain aspect ratios
- **Lazy Loading Support** - Optimized image loading for better performance
- **Full-Width Support** - Images can extend to full viewport width on mobile
- **Responsive Video Embeds** - Videos maintain 16:9 aspect ratio on all devices

### Tables & Forms
- **Horizontal Scroll Tables** - Tables scroll horizontally on mobile to prevent layout breaking
- **Touch-Friendly Forms** - All form inputs sized for easy mobile interaction
- **16px Input Font** - Prevents unwanted zoom on iOS devices
- **Full-Width Search** - Search forms stack vertically on mobile

### Utility Classes
- `.hide-on-mobile` - Hide elements on screens < 768px
- `.show-on-mobile` - Show elements only on screens < 768px
- `.mobile-text-center` - Center text on mobile devices
- `.mobile-text-left` - Left-align text on mobile devices

### Performance
- **Reduced Motion Support** - Respects user preferences for reduced animations
- **Optimized Animations** - Smooth transitions that don't impact performance
- **Mobile-First CSS** - Efficient stylesheet loading with mobile styles as baseline

### Accessibility
- **Skip Navigation Link** - Keyboard users can skip to main content
- **Visible Focus States** - All interactive elements have clear focus indicators
- **WCAG AA Compliant** - Meets accessibility standards for touch targets and contrast

## Brand Colors

## Installation

1. Upload the theme folder to `/wp-content/themes/`
2. Activate the theme through WordPress Admin → Appearance → Themes
3. The theme will automatically create Home and Blog pages and configure them
